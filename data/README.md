# Dataset Information

## Dataset
CIC-IDS2017 — Tuesday Working Hours

## File Used
`Tuesday-WorkingHours.pcap_ISCX.csv`

## Source
Canadian Institute for Cybersecurity (CIC),  
University of New Brunswick.

## Official Dataset Page
https://www.unb.ca/cic/datasets/ids-2017.html

## Dataset Contents
The selected Tuesday dataset contains network traffic records belonging to
the following classes:
- BENIGN
- FTP-Patator
- SSH-Patator

## File Availability
The original CSV file is included in this repository.

The notebook contains the complete preprocessing workflow and can be run
using the downloaded dataset.

## Purpose
The dataset is used for data preparation and preprocessing as part of the
SWYNEX Technologies internship project.
